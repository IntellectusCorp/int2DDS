## 2. Referenced Rust crates (not vendored)

int2DDS uses several Rust crates (e.g. mio, tokio, serde, chrono, rand, etc.)
as build and runtime dependencies. These are fetched from crates.io at build time
and are not vendored into this repository. Please refer to each upstream project
for full license details. An up-to-date list of dependencies can be found
in `Cargo.toml`.
